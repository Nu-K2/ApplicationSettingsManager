# README

## Практическая работа №1: Реализация паттерна «Одиночка» (Singleton) в C#

**Цель работы:** Закрепить теоретические знания по теме «Назначение и виды паттернов» и получить практические навыки реализации паттерна «Одиночка» (Singleton) в консольном приложении на языке C#.

---

## Описание проекта

Консольное приложение **«Менеджер настроек приложения»**, демонстрирующее работу паттерна «Одиночка» для централизованного хранения и управления настройками.

Доступ к менеджеру настроек осуществляется из разных точек программы, но всегда возвращается **один и тот же экземпляр**.

### Демонстрация единственности экземпляра

- Выводится результат `ReferenceEquals(manager1, manager2)`.

Это явное доказательство корректной работы паттерна.

## Реализация паттерна «Одиночка»

### Класс `SettingsManager`

```csharp
class SettingsManager
{
    // Приватное статическое поле для хранения единственного экземпляра
    private static SettingsManager? _instance;

    // Приватный конструктор
    private SettingsManager()
    {
        _settings = new Dictionary<string, string>();
    }

    // Публичный статический метод получения экземпляра
    public static SettingsManager GetInstance()
    {
        if (_instance == null)
        {
            if (_instance == null)
            {
                _instance = new SettingsManager();
            }
        }
        return _instance;
    }

    private readonly Dictionary<string, string> _settings;
    // ...
}
```

**Ключевые элементы паттерна:**
- ✅ Приватный конструктор.
- ✅ Приватное статическое поле `_instance` для хранения единственного экземпляра.
- ✅ Публичный статический метод `GetInstance()` — создаёт экземпляр при первом вызове и возвращает сохранённый при последующих.

## Хранение настроек (бизнес-логика)

Класс `SettingsManager` содержит коллекцию `Dictionary<string, string>` для хранения настроек.

### Методы класса

| Метод | Описание |
|-------|----------|
| `void SetSetting(string key, string value)` | Добавляет или обновляет настройку. |
| `string? GetSetting(string key)` | Возвращает значение настройки по ключу (или `null`, если ключ не найден). |
| `void ShowAllSettings()` | Выводит все сохранённые настройки на экран. |
| `void ClearSettings()` | Очищает все настройки. |
| `bool RemoveSetting(string key)` | Удаляет настройку по ключу. |
| `int GetNumberOfSettings()` | Возвращает текущее количество настроек. |

## Подтверждение действий

После каждой операции (добавление, изменение, удаление, очистка) выводится подтверждающее сообщение с текущим количеством настроек.

**Примеры:**
- «Настройка с ключом = THEME и значением = DARK успешно добавлена. Настроек в коллекции: 3».
- «Настройка с ключом = THEME и значением = LIGHT успешно обновлена. Настроек в коллекции: 3».
- «Настройка с ключом = THEME и значением = DARK успешно удалена. Настроек в коллекции: 2».

## Особенности реализации

- **Потокобезопасность:** используется двойная проверка `if (_instance == null)` внутри `GetInstance()` (хотя без явной блокировки — это базовая версия; для полноценной потокобезопасности рекомендуется `lock` или `Lazy<T>`).
- **Нормализация ключей:** ключи приводятся к верхнему регистру (`ToUpper()`) и обрезаются по первому пробелу, что обеспечивает единообразие хранения.
- **Гибкость ввода:** ответы «y»/«n» принимаются как на латинице, так и на кириллице («у»/«н»).
- **Отмена операций:** все изменяющие действия требуют подтверждения.
- **Инкапсуляция:** словарь `_settings` доступен только через методы класса.
